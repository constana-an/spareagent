# 使用别人分享的算力（成员指南）

任务会在小组主人的 Mac 上、用主人自己的 ChatGPT 额度运行。你只需要一个浏览器，手机或电脑都可以，不用安装任何软件，也不用付钱。

## 打开邀请链接

1. 打开主人私下发给你的完整邀请链接（形如 `https://….ts.net:8443/#join=…`）。证书由浏览器直接信任，不需要导入 `ca.pem`，也不需要 Tailscale（运营者已把成员网页开放到互联网，D-102）。
2. 阅读说明并勾选同意，就加入了小组。

- 登录在这个浏览器里保持 90 天。过期后重新打开同一个邀请链接，或在「用邀请码加入」里输入邀请码，会回到你原来的账号和任务记录，不会多占小组名额。
- 点「退出登录」后，这个浏览器就不再记得你。
- 邀请链接和邀请码只给你一个人用，不要发到群里或截图外传。
- 打不开时：先确认链接完整、没有被截断；仍打不开请让主人联系运营者。出现证书警告时不要继续访问，向主人要新链接。旧的 IP 地址链接用的是私有证书，不能代替新版入口。
- 如果主人发来的邀请说明里写着「先安装 Tailscale」，说明运营者还没有开放公网入口：先安装并打开 Tailscale，登录运营者的 tailnet 或接受共享给你的服务器，再打开链接。

## 页面布局

左侧栏有三项：

| 栏目 | 内容 |
|---|---|
| 我的任务 | 你的工作区：新建任务、任务列表和任务详情 |
| 小组 | 小组名称、成员人数和人数上限 |
| 分享你的 Mac | 可选。提交任务不需要这一步；只有你也想把自己的 Mac 分享给小组时才用 |

左侧栏底部可以切换中文和英文，也可以退出登录。页面顶部会显示运营者是否开启了真实执行。

## 提交任务

点工具栏的「＋ 新任务」：

1. **描述你要的结果**：写清楚面向谁、什么语气、要计算或修改什么。可以点「示例」快速填入。所有任务都是通用任务，可以讨论问题、写作、翻译、整理表格和画图表、修改你上传的代码文件、用代码画图（SVG / PNG）。想要翻译，就在需求里写目标语言；想要某种格式（例如 Word 或 Excel），也直接写出来。
2. **附件（可选）**：最多 5 个，每个不超过 20 MB。可以拖进来、粘贴截图，或点「选择文件」。支持文档（txt、md、docx、pdf）、表格（csv、xlsx、json）、图片（png、jpg）和常见代码文件，完整列表见「支持的格式」。
3. **需要联网**：任务默认不联网，只能使用你写的需求和上传的材料。需要查资料时打开这个开关，任务只会派给允许联网的设备，回答里会列出用到的网址。
4. **高级**（通常不用改）：
   - 目标设备：小组里有几台设备时可以选；每台设备后面写着在线 / 离线和是否自动批准，下面显示你在这台设备上过去 24 小时用了多少个任务、多少分钟，以及主人有没有给你单独设上限。
   - 最长运行时间（秒）：不能超过主人设的上限；主人选择不限时可以留空。
   - 执行方式：默认真实执行；「模拟」只走一遍流程，交付占位文件。
5. 点「提交任务」。材料会经过运营者的服务器，并在主人的 Mac 上处理。

提交框右上角会提示设备在线还是离线。设备离线时也可以提交，任务会排队等它上线。

## 看进度和取结果

任务列表显示每个任务的状态、提交时间和所在设备，可以搜索。点一个任务会打开它的详情：一边是任务属性，另一边有两个标签页：

- **结果**：结果文件的名称、大小和完成时间，可以预览、单独下载或「全部下载」。下载时会自动核对 SHA-256。
- **日志**：按时间列出的事件、运行日志和检查报告，排查问题时用。

可以关掉页面，完成后再回来下载。点工具栏的「完成时提醒我」，任务结束时浏览器会弹出通知。

| 你看到的 | 意思 |
|---|---|
| 排队中 · 第 N 位 | 在等主人的 Mac 空出来 |
| 等待批准 | 主人没开自动批准，要逐个批准你的任务 |
| 排队中 · 小组主人已暂停分享 / 设备离线 | 主人不在线；回来后自动继续，10 分钟内没被接单会超时 |
| 排队中 · 设备已达到今日任务上限 | 主人给这台设备设的每日任务数用完了 |
| 排队中 · 你今天的任务数 / 执行分钟已到主人设的上限 | 主人给你单独设了每日上限；过去 24 小时的用量降下来或主人调高后自动继续 |
| 排队中 · 主人的订阅额度暂时用完 | 主人的 ChatGPT 额度在恢复中 |
| 排队中 · 主人没有允许这类任务需要的工具 | 多半是任务要联网，而主人关掉了联网 |
| 运行中 · xx% | 正在主人的 Mac 上执行 |
| 设备中断 · 正在重新排队 | 主人那边中断了，会自动重新运行一次 |
| 正在检查结果 | 平台在检查交付文件的格式和完整性 |
| 完成 · 已检查格式，内容请自行核对 | 文件齐全、能打开；写得对不对，系统没法替你判断 |
| 没有完成 | 显示中文原因和建议，例如输入不合格、超时、结果未通过检查、订阅额度已用完、Codex 拒绝执行 |

- 任务结束前随时可以「取消任务」；运行中的任务会先显示「正在取消」，主人的 Mac 确认停止后才显示「已取消」。
- 想换个说法重做，点「改一改再提交」，上次的需求会填回新任务（附件需要重新添加）。
- 平台只检查格式和完整性，**译文质量、分析结论和代码改动请你自己核对**。
- 如果运营者还没有开放真实执行，任务会以「模拟」方式完成：流程完整，但交付的是占位文件，不是真正的结果。

## 被暂时断开或移出小组

- 页面显示「主人已暂时断开你的连接」时，你暂时不能提交新任务，未完成的任务已停止；历史记录会保留，主人恢复连接后可以继续使用。
- 被移出小组后，原来的邀请码也会失效，需要主人重新邀请你。

## 隐私

你的需求和附件会经过运营者的服务器，并由主人的 Mac 上的 Codex 处理。不要上传密码、证件号、银行信息或不想让主人和运营者看到的内容。主人的 ChatGPT 凭据只留在主人自己的 Mac 上，你也不需要提供任何账号。
