# 使用别人分享的算力（成员指南）

任务会在小组主人的电脑上、用主人自己的 ChatGPT 额度运行。你通过浏览器使用；当前私网部署还需要 Tailscale。

## 开始前（一次性）

1. 安装并打开 Tailscale，登录运营者的 tailnet，或接受运营者共享给你的服务器。确认 Tailscale 显示已连接。
2. 打开主人私下发给你的完整 `https://…ts.net:8443/` 邀请链接。新版入口使用浏览器信任的 HTTPS 证书，不需要导入 `ca.pem`，也不用在终端检查连通性。

打不开时：先检查 Tailscale 是否已登录并连接到正确的私网；已连接仍打不开，请让运营者检查服务。出现证书警告时不要继续访问，向主人索取新链接。旧 IP 地址链接可能仍使用私有证书，不能代替新版入口。

## 加入小组

打开小组主人私下发给你的邀请链接（`https://HOST.ts.net:8443/#join=...`），阅读并勾选同意，就加入了。登录在这个浏览器里保持 90 天；过期后重新打开同一个邀请链接（或输入邀请码），会回到你原来的账号和任务记录，不会多占小组名额。点「退出登录」后就不再记得你。邀请码不要发到群里或截图外传。

## 提交任务

提交页会显示你在每台设备上过去 24 小时用了多少个任务、多少分钟，以及主人有没有给你单独设上限。

在「新任务」里：

1. 选择 **任务种类**：**通用任务**（讨论问题、写作、翻译、整理表格、修改你上传的代码文件、用代码画图，附件可选），或专门的翻译文档（docx / md / txt）、分析表格（csv / xlsx）、修改代码，以及代码审查、修复问题、补充测试。专门种类对结果检查得更严格。标着「暂时仅模拟」的种类还没开放真实执行。任务默认**不联网**，只能使用你上传的材料；需要查资料时勾选「需要联网」，任务只会派给允许联网的设备（默认允许；主人关掉了就会排队并说明原因），回答里会列出用到的网址。
2. **上传材料**：最多 5 个，每个不超过 20 MB。翻译选目标语言和交付格式；代码类填写公开仓库地址和固定的 commit。
3. 写清楚你的 **需求**，提交。材料会经过运营者的服务器，并在主人的电脑上处理。

## 看进度和取结果

| 你看到的 | 意思 |
|---|---|
| 排队中 · 第 N 位 | 在等主人的电脑空出来 |
| 排队中 · 小组主人已暂停分享 / 设备离线 | 主人不在线；回来后自动继续，10 分钟内没回来会超时 |
| 排队中 · 已达今日上限 | 主人设的每日任务数用完了 |
| 排队中 · 你今天的任务数/执行分钟已到主人设的上限 | 主人给你单独设了每日上限；过去 24 小时的用量降下来或主人调高后自动继续 |
| 运行中 · xx% | 正在主人的电脑上执行 |
| 设备中断 · 正在重新排队 | 主人那边中断了，会自动重新运行一次 |
| 正在检查结果 | 平台在检查交付文件的格式和完整性 |
| 完成 | 在「交付文件」里下载；下载时会自动核对 SHA-256 |
| 失败 | 显示中文原因和建议，例如输入不合格、超时、结果未通过检查、Codex 拒绝执行 |

任务结束前随时可以取消（运行中的任务会通知主人的电脑停止）。平台只检查格式和完整性，**译文质量和分析结论请你自己核对**。

如果运营者还没有开放真实执行，你提交的任务会以「模拟」方式完成：流程完整，但交付的是占位文件，不是真正的结果。
