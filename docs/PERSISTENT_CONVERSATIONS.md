# 持续对话

任务结束后，在结果下方点击“继续对话”，输入追问并提交。新一轮会带上这段对话的历史消息、原附件和最近的结果文件。刷新网页后，重新打开其中任一任务，可以查看已保存的对话。

“新任务”会开始一段独立对话，不会自动读取其他对话。追问沿用同一成员、小组和提供者设备；每一轮仍单独批准、计量，也可以取消。

对话关系和消息保存在服务器数据库中。模型每轮收到最近 20 条历史消息、最多约 60,000 字符，以及本轮需求；原始问答记录仍可查看。原附件持续复用，结果文件最多带上最近 20 个。

服务器通过现有租约附件协议发送历史消息，兼容当前 Worker，无需先升级主人端 App。上下文文件只允许持有有效租约的设备下载，其他成员不能引用或读取这段对话。

这次更新不会把过去互不关联的独立任务自动合并。可以打开旧任务，点击“继续对话”，从该任务开始延续。
